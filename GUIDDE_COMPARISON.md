# Guidde and Stepfilm: feature and workflow comparison

**Prepared November 12, 2026.** Guidde capabilities below summarize its currently published Help Center documentation. Stepfilm status comes from the prototype code, README, and acceptance notes; code presence does not mean the feature has passed its manual acceptance check.

## At a glance

Guidde is a hosted video and documentation platform with browser, desktop, and mobile capture, AI-assisted authoring, shared workspaces, and many publishing options. Stepfilm now supports a hybrid browser workflow: it records the selected tab continuously while capturing separate ordered screenshots, then lets the creator review and insert the recording as a video step. It covers a useful local create-edit-export loop, with a smaller capture and publishing surface.

## Stepfilm's current end-to-end path

1. Start the local app with `python3 server.py`, then load `capture-extension` as an unpacked Chrome extension. Alternatively, open an existing Mimik HTML guide or a saved Stepfilm project.
2. Start tab or screen/window capture and optionally enable microphone narration. Tab mode captures click-triggered screenshots; screen/window mode uses manual checkpoints. Transfer a phone video to the computer to import it as a clip step. Stop opens the editor.
3. Choose **Transcribe captured narration** to create a full transcript, per-step instructions, and timed captions aligned to screenshot intervals. Edit captions/timing, select a translation, preview it, and choose recorded or synthetic narration per step.
4. Review the captured video separately from the screenshots. Insert it after the selected scene where it belongs; reorder, duplicate, or remove scenes and edit descriptions. Add annotations, blur/redaction, and focus to screenshot scenes. Optionally draft titles, descriptions, instructions, and callouts with AI; generate per-step AI voiceover.
5. Export the MP4 locally with caption burn-in and the selected brand theme. Download VTT/SRT timed to the rendered step order or to the original capture. Print/save a PDF or export a SCORM 1.2 course package.
6. Save the editable `.stepfilm.json` project, export a portable offline ZIP with video/caption assets, or export HTML/Markdown. The ZIP is manually shared; it does not create a hosted link.

The hybrid capture and mixed-media export path has been exercised manually in Chrome, including popup reopen, simultaneous screenshot capture, stop/handoff, clip preview/insertion, reordering, project save/open, video-only capture, and MP4 export. The broader acceptance document still requires three consecutive capture runs, annotation/redaction visibility, viewer comprehension, and three consecutive MP4 exports before the full parity milestone can pass.

## Practical parity read

For a solo browser tutorial, Stepfilm now covers most of the create → edit → narrate → caption → export loop: tab or screen/window capture → optional mic and step screenshots → AI draft/transcript/video analysis → multi-select editing, annotations, themes, captions and translation → MP4/PDF/SCORM/portable ZIP. It is closer to the Guidde threshold for local single-creator output, pending live AI and hands-on UX verification. The largest remaining gaps are hosted collaboration/access controls, native mobile/desktop capture and camera/system audio, precise word-level fallback alignment, direct third-party integrations, and mature template/media-import tools.

The current prototype provides a broad local authoring/export workflow and a portable package, but is not a hosted collaborative Guidde replacement. Native mobile capture, system audio/camera, hosted links/accounts, direct integrations, and true forced alignment remain gaps. Realtime TTS is opt-in and still needs live API verification. Automated tests cover simulated media/export paths; real Chrome source/mic permissions, OpenAI calls, and a live LMS remain manual checks.
